# ローカル LLM（Ollama）と Claude Code の論文比較（2026-10-09）

## 条件
- 題材: TALIS 2024（oecd_talis_teacher_survey / talis_collaboration_ict）。同じ事実ファイル・同じ指示・同じ見本（別題材の完成版2本）。
- Ollama: `http://192.168.128.62:11434`（v0.40.1）。gemma4:12b と qwen3.5:9b（shosetsu は小説向けなので除外）。1回の生成のみ（JSON モード、think なし、num_ctx 49152、温度 0.3）。

- **注意**: Claude 側は「執筆→査読→修正」を経た完成版、Ollama 側は1回で書かせた生の出力。パイプライン全体の比較であり、モデル単体の比較ではない。
- 最初の試行は、見本に同じ題材の Opus の論文が入っていて、gemma が写してしまったため無効にした（`tools/ollama_paper.py` に、同じ題材が見本に入ったら止まる検査を入れた）。2回目は事実ファイルが別の角度のものだったため無効にし、3回目（これ）で揃えた。

## 読み取り
- 数値の書式と因果の慎重さは、gemma4 は守れた。qwen3.5 は最上級の誤り、結果に書いていない相関の主張、方法と結果の矛盾があった。
- 差が出たのは「深さ」。Ollama の2つは、日本の位置と RQ2 の r を述べるだけで、AI利用が自信よりも少人数グループの指導と強く関連する、という対照や、除外による頑健性の確認がない。
- ローカルは速く、費用もかからないが、単独では公表用の水準に届かない。使うなら、下書き（骨格づくり）に使い、数値の検査（`tools/check_numbers.py`）と Claude の査読・修正を通す。qwen3.5:9b は論文には向かない。
- これは1題材・1回の生成での比較。ばらつきは調べていない。

## 追記：Ollama の下書きを Claude で校正する流れ（2026-10-09）
流れ: Ollama の下書き（1回の生成）→ Sonnet が校正（数値・順位・最上級を元データで確かめ、論理の誤りを直し、足りない内容を補い、4,940字以内に収める）→ 数値検査 → 匿名採点（Opus、10点満点）。
校正の指示書: 校正者への指示に、頑健性の確認（日本を除く・注意付きの国を除く・1か国ずつ除く）、探索したペア数と多重比較の基準、対照指標との比較、の観点を含めた。

| | 生（Ollama） | 校正後 | Opus 完成版（比較用） |
|---|---|---|---|
| gemma4:12b | 5点（正確さ8／深さ4） | **8点**（8／8／慎重さ9） | 8点（9／9／8） |
| qwen3.5:9b | 2点（3／3） | **9点**（9／9／9） | |

匿名採点の順位: qwen校正後 > Opus完成版 > gemma校正後 > gemma生 > qwen生。

### 読み取り
- **校正を通すと、公表に近い水準まで上がる。** 生の出力で最も悪かった qwen3.5:9b（2点）も、校正後は誤りがなくなり、頑健性と多重比較がそろった（9点）。校正者は、最上級の誤り（日本のAI利用を「最も低い」）、方法と結果の矛盾、他の題材の文献の引用（Robinson 1950、Shen and Tam 2008）などを直した。
- **ただし、この比較は有利に出ている。** (1) 校正の指示書に、Opus の論文の査読で見つかった観点（除外による頑健性、ボンフェローニ、対照指標）を入れた。校正者は、その答えに沿って直せた。(2) 採点も同じ観点で行った。(3) Opus 完成版は、4ページに収めるために削った版で、採点では「同程度以上に関連」の言い過ぎが減点された。(4) 1題材・1回だけ。
- **ローカルの下書きの役割は、骨格づくり。** 校正者の見積もりでは、そのまま使えたのは約半分。数値の検査と校正を省くと、公表できない（生の qwen は最上級の誤りが3か所）。
- **残った誤り**: gemma の校正後に、方法の「日本と同じ値の国・地域はなかった」が誤り（学習の計画・管理は日本とオーストリアがどちらも17.8%）。校正後にも誤りが1つ残ることがあるので、最後の査読は省けない。
- **費用と時間**: Ollama の生成は2〜4分で無料。校正は Sonnet のサブエージェントで約2.5分。Opus が書いて Sonnet が査読して直す流れ（約10分）と比べ、Claude の使用量は減るが、ゼロにはならない。

### 評価の道具の不備（修正済み）
`tools/compare_papers.py` は、引用を全題材の文献表から探すため、他の題材の文献（生の gemma の Robinson 1950 ほか）も「対応あり」と数えていた。この題材の表にない引用を別に数えるよう直した。
