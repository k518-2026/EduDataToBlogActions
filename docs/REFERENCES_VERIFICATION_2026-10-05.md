# 参考文献の実在確認（2026-10-05）

`src/academic_contexts.py` の `curated_references`（重複を除いて 97 件）を、外部の書誌データで 1 件ずつ照合しました。
結論：**そのまま使える文献は 3 割ほどで、和文の学術論文は大半が見つかりませんでした。**
確認できたものだけを残し、`data/references_verified.json` に証拠つきで登録しています。

## 結果

| 区分 | 件数 | 扱い |

| 実在するが書誌が違っていたので直した、または差し替えた | 27 | 題名・出版社・年・DOI・誌名の誤りを訂正（下表） |
| 見つからず削除した | 40 | 和文の学術論文が中心。著者・題名・誌名の組が見つからない |

照合の方法：欧文は Crossref（DOI）。和文は CiNii Research（著者名＋題名）と NDL サーチ（書籍・報告書）。
公的資料は文部科学省・大学入試センター・ITU などの公式ページを Web 検索で確認しました。

## コード側の対策

- `tests/test_academic_citations.py::test_curated_references_are_verified`：`curated_references` に登録外の文献があるとテストが落ちます。
- プロンプト：引用してよいのは一覧の文献だけ、本数の下限なし、と明記しました。以前は「実在する文献を 8 本以上」と求めており、足りない分をモデルが作る原因でした。
- `synchronize_citations_and_references`：
  - 以前は、引用に対応する文献が見つからないと、**偽の参考文献（「教育データ分析と指導法改善に関する実証的検討. 教育学研究, 1 (1) ：1-10.」）を自動で作っていました。** 廃止しました。
  - いまは、参考文献を検証済みの一覧だけから組み直し、一覧にない引用が本文にあれば `UnverifiedCitationError` で止まります（モデルの切り替えを経て、全部だめなら生成失敗）。

## 残る課題

- `academic_contexts.py` の `fallback_*`（テスト専用のひな形本文）は、いまは本番で使われませんが、古い主張（TIMSS パラドックスなど）が残っています。引用は検証済みの文献に合わせて整えましたが、本文自体は削除の候補です。
- 本文中の引用の言い回しが、文献の内容と合っているかは確認していません（題名から言える範囲に抑えるようプロンプトで指示）。公開前に人が読む必要があります。
